# Contributing to MFR Adaptive Intelligence Core Pro

Thank you for your interest.

## Principles

This component follows the FathiMind doctrine:

1. No strong claim at low confidence.
2. Independence is enforced.
3. Every decision leaves a replayable trace.
4. The system must suggest its own next improvement.
5. Provisional findings only.

## How to contribute

1. Fork the repository.
2. Create a feature branch.
3. Add or improve tests (`test_mfr_core_pro.py`).
4. Keep the core dependency-free (stdlib only).
5. Run the full test suite before submitting a PR.
6. Describe the change clearly and link any related issue.

## Code style

- Python 3.10+
- Type hints preferred
- Clear, readable names
- Prefer explicit over clever

## Questions

Open an issue with the `question` label or discuss in the parent FathiMind repository.
